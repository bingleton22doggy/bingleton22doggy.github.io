SHATTERED MEMORIES - FULL PACKAGE

This package contains both deliverables and their source projects.

1. Web_Version/ contains the standalone browser game source. It does not require Base44.
   To run locally: install Node.js, open the project folder, run `npm install`, then `npm run dev`.
   To publish: run `npm run build` and upload the contents of `dist/` to a static host.

2. PSP_Project/ contains the PSP homebrew source project (Makefile, C source, and assets).
   Build using the PSP toolchain described in its README.

3. The three ZIP files below are ready-made separate downloads of each package.
